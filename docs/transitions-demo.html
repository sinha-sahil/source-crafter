Easing Functions

Controls acceleration. Click any to see the motion curve.

linear
Constant speed. For spinners, progress bars.
ease-out
Fast start, slow end. Best for ENTER transitions.
ease-in
Slow start, fast end. Best for EXIT transitions.
ease-in-out
Slow start and end. For symmetric animations.
m3-emphasized-decel
Material Design 3 primary entrance easing.
m3-emphasized-accel
Material Design 3 primary exit easing.
m3-standard
Material Design 3 standard motion.
spring
Overshoots and settles. Playful, iOS-style.
